# Your first Pump.fun batch

Suppose you want three coins with the same artwork. What you should get back is **three distinct mint addresses** if all three confirm. Here’s how to make that order and recognize the result.

1. Open [masslauncher.fun](https://masslauncher.fun/) or [@MassLauncherBot](https://t.me/MassLauncherBot). If you already use the bot, link that Telegram account to the website to use the same credits. You don’t need a browser wallet to sign in.
2. Open **Buy Credits**. Choose a quantity, review the SOL total and use the deposit instructions shown for that open payment. Wait for your credit balance to update. You don’t need to buy 25 credits to launch three coins.
3. In **Coins**, prepare a profile: name, ticker, artwork and any links you want. Check the preview before saving. If importing from a contract address doesn’t bring in the original image, upload an image you have permission to use. [Troubleshoot an image import](https://masslauncher.fun/blog/pump-fun-metadata-image-import).
4. Select that saved profile and set the launch quantity to **3**. Review the account cost and any extras before submitting. This action creates real tokens; the public pricing calculator does not.
5. Open the batch result. Follow the mint link on each successful row. If two rows are successful and the third is pending, save the first two addresses and wait for the third. Don’t launch three more to try to get one missing result.

**Deposit not showing up?** Check the public transaction signature and the payment window, then use the support link in [the bot](https://t.me/MassLauncherBot). Never send a second payment just to check the first one.
