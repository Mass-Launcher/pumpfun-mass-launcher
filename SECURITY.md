# Security Policy

MassLauncher is a closed-source hosted service. To report a security
vulnerability, contact us privately:

- **Twitter DM**: [@masslauncher](https://x.com/masslauncher)
- **Telegram**: send `/contact` to [@MassLauncherBot](https://t.me/MassLauncherBot)

We respond within 48 hours.

Do **not** open a public issue with vulnerability details.

For more, see the [main repo's SECURITY.md](https://github.com/Mass-Launcher/MassLauncher/blob/main/SECURITY.md).
